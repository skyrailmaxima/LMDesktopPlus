DIGITALVAPOR

A vapor//matrix theme pack — tokens, utilities, components and window chrome in one drop-in stylesheet. Paste digitalvapor.css, link it, and build webpages or app UIs in the same neon-on-black grammar. Add digitalvapor.js for the matrix rain and zero-config interactions.

01 · Foundation

Tokens & setup

Everything reads CSS custom properties. Override them on :root (or any scope) to re-skin an entire build — swap the accent, soften corners, dial the blur.

<link rel="stylesheet" href="digitalvapor.css"> <script src="digitalvapor.js" defer></script> /* re-skin in one place */ :root{ --dv-accent: var(--dv-cyan); /* magenta → cyan */ --dv-radius: 4px; /* soften corners */ --dv-blur: 14px; /* heavier frost */ }
