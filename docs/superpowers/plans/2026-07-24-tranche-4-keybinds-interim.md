# Tranche 4 Interim Plan — Keybind Editor

> Interim design notes before implementation. Builds on Tranche 1–3 rails
> (`SETTINGS_TABS`, `SCENE_BINDINGS`, `POST_ROUTES`, `dispatch_command`).
> Parent plan: `2026-07-24-dispatch-refactor-stage-c.md` Tranche 4 / gaps Task 17.

**Goal:** Let users edit LMDesktopPlus-owned Hyprland binds through Settings →
Keybinds, writing only a generated overlay file — never arbitrary user
`hyprland.conf` content.

**Non-goals:** Cinnamon keybind editing; rewriting community Hyprland configs;
free-form shell actions as bind targets.

---

## Ownership model (mirror theme overlay)

| Path | Role |
|---|---|
| `~/.config/lmdesktopplus/hypr-binds.conf` | **Owned file** — generated; rewritten by LMDP |
| `packages/hyprland/hypr/hyprland.conf` (or user hyprland.conf) | Must `source = ~/.config/lmdesktopplus/hypr-binds.conf` when LMDP-owned (same guard as `hypr-generated.conf` in `theme.py`) |

Guard rules (from `theme.py`):

1. Create `hypr-binds.conf` with a header `# Generated by LMDesktopPlus.`
2. Only append `source = …/hypr-binds.conf` into a hyprland.conf that already
   contains `LMDesktopPlus` ownership markers.
3. Never invent or overwrite unrelated bind lines outside the owned file.

## Data model — maps first

```python
# Canonical defaults (id → bind spec). UI and file generation both consume this.
DEFAULT_BINDS: dict[str, dict[str, str]] = {
    "terminal": {"combo": "SUPER, Return", "dispatch": "exec, kitty", "label": "Terminal"},
    "rofi": {"combo": "SUPER, SPACE", "dispatch": "exec, rofi -show drun", "label": "Launcher"},
    "agent": {"combo": "SUPER, A", "dispatch": "exec, lmdesktopplus", "label": "Agent surface"},
    "kill": {"combo": "SUPER, Q", "dispatch": "killactive,", "label": "Close window"},
    "fullscreen": {"combo": "SUPER, F", "dispatch": "fullscreen,", "label": "Fullscreen"},
    "float": {"combo": "SUPER, V", "dispatch": "togglefloating,", "label": "Toggle floating"},
    "lock": {"combo": "SUPER, ESCAPE", "dispatch": "exec, loginctl lock-session", "label": "System lock"},
}

# Allowlisted dispatch prefixes — reject anything else from UI.
ALLOWED_DISPATCH_PREFIXES: tuple[str, ...] = (
    "exec,",
    "killactive,",
    "fullscreen,",
    "togglefloating,",
    "workspace,",
    "movetoworkspace,",
)
```

User overrides live in settings or a small JSON beside the conf:

```text
~/.config/lmdesktopplus/keybinds.json   # { "terminal": {"combo": "SUPER, T"}, … }
```

Merge: `effective = {**DEFAULT_BINDS[id], **overrides.get(id, {})}` per id.
Generation walks `DEFAULT_BINDS` keys (stable order), not free-form UI rows.

## Adapter / service shape

Prefer a thin **`KeybindsAdapter`** (`id = "keybinds"`) for consistency with Stage C:

| Command | Payload | Behavior |
|---|---|---|
| `list` | `{}` | Snapshot: effective binds + `file` path + `sourced` bool |
| `set` | `{id, combo?}` | Validate id ∈ DEFAULT_BINDS; parse combo; write json + regenerate conf |
| `reset` | `{id?}` | Clear one override or all; regenerate |
| `apply` | `{}` | Rewrite conf from current effective map (idempotent) |

```python
def command(self, name, payload):
    return dispatch_command(self._commands(), name, payload, adapter_id=self.id)
```

Register in `ADAPTER_CAPABILITIES` and `ApplicationState`.
Add `POST` is already covered by `/api/v1/adapter/keybinds` prefix — **no new
`POST_ROUTES` entry required**.

---

## Combo validation (edge branches only)

- Normalize: trim, uppercase modifiers (`SUPER`, `ALT`, `CTRL`, `SHIFT`)
- Reject empty, newlines, `;`, shell metacharacters in combo
- Optional: simple grammar `^(SUPER|ALT|CTRL|SHIFT)(, (SUPER|…))*(, [A-Za-z0-9]+|, (RETURN|SPACE|ESCAPE|TAB))$`
- Dispatch field is **never** taken from the client for default rows — only combo
  edits; dispatch stays from `DEFAULT_BINDS[id]["dispatch"]`

## UI (Settings → Keybinds)

Replace static `renderKeybinds()` list with:

1. Rows from `adapters.keybinds.binds` (hash map → `Object.entries` / ordered ids)
2. Per row: combo `<input data-keybind-id="terminal">` + label + reset button
3. Footer: `RESET ALL` / note that Hyprland must source the overlay

Wire through existing rails:

```js
// SETTINGS_TABS already points at renderKeybinds — swap body only
{ sel: "[data-keybind-id]", type: "change", run: (el) => setKeybind(el.dataset.keybindId, el.value) },
{ sel: "[data-keybind-reset]", run: (el) => resetKeybind(el.dataset.keybindReset) },
```

Use `adapterCommand("keybinds", "set", { id, combo })`.

## File format (`hypr-binds.conf`)

```conf
# Generated by LMDesktopPlus. Do not edit by hand — use Settings → Keybinds.
bind = SUPER, Return, exec, kitty
bind = SUPER, SPACE, exec, rofi -show drun
# …
```

One `bind =` line per DEFAULT_BINDS entry. Atomic write (temp + replace) like
`atomic_write_json`.
